# MORNINGO Café

Статический сайт кафе, подготовленный для публикации на GitHub Pages.

## Структура

- `index.html` — главная страница
- `style.css` — весь дизайн и адаптив
- `script.js` — меню, фильтры, корзина и бронь без бэкенда
- `assets/` — 20 фотографий в WebP
- `favicon.svg` — favicon

## GitHub Pages

1. Создайте репозиторий и загрузите содержимое этой папки в корень репозитория.
2. В `Settings → Pages` выберите `Deploy from a branch` и ветку `main` / папку `/ (root)`.
3. После публикации сайт откроется по адресу GitHub Pages.

Все пути относительные, поэтому проект также корректно работает в репозитории вида `username.github.io/morningo/`.

## Что заменить перед публикацией

В `index.html` замените демонстрационные контакты, адрес, телефон, почту и ссылки на соцсети. Бронь и заказ работают через `mailto:` и не требуют сервера.
